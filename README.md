## Descrição

O **Jogo Mario** é um projeto de jogo desenvolvido como atividade acadêmica, inspirado na mecânica clássica de jogos de plataforma.

O jogador controla o personagem Mario, que deve pular para evitar os obstáculos presentes no cenário. Durante a partida, um cano se movimenta em direção ao personagem e o jogador precisa realizar o salto no momento adequado para evitar a colisão.

Caso Mario colida com o obstáculo, o jogo entra em estado de Game Over.

O projeto também foi organizado utilizando Git e GitHub, com branches, commits e integração entre as versões de desenvolvimento e principal.

## Objetivo

O objetivo do projeto é desenvolver uma versão simples e funcional de um jogo inspirado no Mario, colocando em prática conceitos de desenvolvimento Front-End e, principalmente, os conhecimentos de Git e GitHub trabalhados na atividade.

O projeto busca praticar:

- Estruturação de páginas com HTML;
- Estilização e animações com CSS;
- Programação e interação com JavaScript;
- Detecção de colisões;
- Controle de estados do jogo;
- Organização de um projeto de software;
- Controle de versões com Git;
- Utilização do GitHub;
- Uso de branches para desenvolvimento;
- Realização de commits;
- Integração da branch de desenvolvimento com a branch principal.

## Funcionalidades

Atualmente, o jogo possui as seguintes funcionalidades:

- Exibição do personagem Mario;
- Exibição do obstáculo;
- Movimentação do obstáculo;
- Sistema de pulo do personagem;
- Animação do pulo;
- Detecção de colisão;
- Interrupção do jogo após a colisão;
- Alteração do personagem para o estado de Game Over.
